# Dataset Directory

Place your authentic e-waste and recycling dataset files here (e.g., `.csv`, `.xlsx`).

> **Note:** In compliance with project integrity standards, no fake or synthetic data is included. Please place your official/verified dataset files here (e.g., from the Global E-waste Monitor, Kaggle, national pollution control boards, or open data repositories).

### Recommended File Naming:
- `raw_ewaste_data.csv` (original unmodified data)
- `cleaned_ewaste_data.csv` (data after cleaning and preprocessing)
